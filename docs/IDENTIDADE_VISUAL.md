# Identidade Visual — Destyn Trips

Marca: **Destyn Trips** · Domínio: [destyntrips.com.br](https://destyntrips.com.br)

Layout base: TravelWorld (Figma) em pixel-perfect; **única diferença visual: o logo**.

## Logo

Arquivos em `frontend/assets/logos/`:

- `destyn-trips-logo.svg` — wordmark + avião/rota
- `destyn-trips-mark.svg` — símbolo

## Favicons

Pacote estilo [RealFaviconGenerator](https://realfavicongenerator.net/) em `frontend/assets/favicons/` (`favicon.ico`, PNG 16/32/48, apple-touch, android-chrome, mstile, safari-pinned-tab, `site.webmanifest`, `browserconfig.xml`). Tags em `frontend/components/head.php`.

## Paleta

| Token | HEX | Uso |

## Tipografia

- **UI / títulos:** Montserrat
- **Cidades / eyebrows decorativos:** Island Moments (script)

## Componentes

Header, footer, search bar, service cards, destination/package cards, experience, gallery, testimonials, subscribe e auth split — todos em `frontend/components/`.
